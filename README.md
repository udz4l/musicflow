# MusicFlow

A two-person Java final project about a music streaming service.

## Environment

- JDK 26
- IntelliJ IDEA
- Maven

## Planned design patterns

- Builder: playlist construction.
- Adapter: local and HTTP music sources.
- Facade: unified application operations.
- Strategy: playback order.
- Observer: playback events.
- Decorator: audio effects.

## Current status

The initial project runs and prints the Java runtime version.

## Run

Open the project in IntelliJ IDEA, select JDK 26,
and run com.musicflow.Main.
